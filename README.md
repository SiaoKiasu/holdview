# Linden Asset Management · 私人账户观察室

**管理员配置账户，朋友用自己的用户名和密码登录，只读查看被分配给他的资产。**

支持多个 Binance 现货账户。固定管理员可以查看所有启用账户，并在网页管理用户、密码、账户绑定、API、本金和手工成本。普通用户只有账户总览、资产持仓和交易记录，不显示管理界面，管理接口也拒绝访问。

## 首次设置

需要 Node.js **24.x**。在项目目录运行：

```bash
npm ci
npm run admin:setup
```

输入固定管理员用户名和密码。命令将生成私密 `.slzb/admin-env.txt`，其中是初始化所需的四项环境变量（密码只保存 scrypt 哈希）。它不会覆盖现有 `.env.local`，也不会自动导入旧用户。

### Vercel

1. 为项目连接 Neon Postgres，并设置 `DATABASE_URL`。
2. 将 `.slzb/admin-env.txt` 中的 `ADMIN_USERNAME`、`ADMIN_PASSWORD_HASH`、`SESSION_SECRET`、`CONFIG_ENCRYPTION_KEY` **分别**填入 Vercel 环境变量。不要把整个文件塞进一个变量；哈希中的 `$` 必须原样保留。
3. Redeploy 一次，使用固定管理员登录网站。没有账户时直接进入管理后台。
4. 「交易所账户」→ 新增账户，填只读 API 和本金；「用户管理」→ 新增用户，设置密码并绑定账户。

**后续增加用户、重置密码、换绑账户、停用用户、修改 API 和成本均在网页生效，不用改环境变量或重新部署。** 固定管理员只通过环境变量变更，网页用户无法提升为管理员。`CONFIG_ENCRYPTION_KEY` 必须备份并长期保留，否则旧账户配置无法解密。

### 本地

将生成的 `.slzb/admin-local.env` 四项合并到 `.env.local`，然后执行 `npm run dev`。该文件已为 dotenv 转义哈希的 `$`；Vercel 使用未转义的 `admin-env.txt`。本地无数据库时，后台配置加密保存到 `.slzb/directory.enc`；有 `DATABASE_URL` 时与云端一致存入数据库。不要把测试环境连接到真实生产数据库。

未配置固定管理员或旧账户时保留 `demo / demo123456` 演示模式。**只要开始填写管理员环境变量，缺少必需配置就会报错，不会退回演示模式。**

旧 `PORTAL_CONFIG_JSON` / `.slzb/accounts.json` 模式保留兼容，但不支持网页管理用户。启用固定管理员后使用独立的新目录，旧文件不会删除或自动导入。可以在网页重新录入；不再需要 `config:export`。

完整说明：[管理员操作指南](docs/ADMIN.md)。默认函数区为 Frankfurt (`fra1`)，交易所接口仍受账户地区及 API IP 白名单限制。

## 登录状态

- 使用一年有效期的持久化 HttpOnly Cookie，活跃请求自动续期，不再每 12 小时退出。
- 刷新页面、关闭页面或重启浏览器后，只要 Cookie 仍保留即可继续查看。
- 主动退出、清除浏览器 Cookie、长期一年未访问、管理员修改密码/绑定、撤销登录或停用用户后，需要重新登录。
- 用户每次请求都重新校验当前权限。停用/撤销配置生效后，下次请求即拒绝访问。
- 同一浏览器的多个标签页会同步登录/退出状态；不同查看账号应使用各自浏览器资料或设备。

## 已实现

- 中文电脑/手机 Portal，密码登录，按用户隔离账户。
- 四项指标：总资产估值（现货 Equity）、已实现盈亏、未实现盈亏、现金（USDT）；单独展示账户本金。
- 自动发现交易对、分页回溯成交，包括当前目录中的已清仓交易对；最近 1,000 笔列表、筛选、CSV 导出及全现货钱包挂单。
- 页面可见时每 60 秒自动刷新；历史回溯显示具体进度，挂单失败和行情缺失分别提示。
- 可选持久净值，24h / 7d / 30d / 90d 曲线。Vercel 每日 Cron 为启用的真实账户保存快照。
- 账户接口只读，没有下单、撤单、提现或转账功能。

## 盈亏口径

**持仓表成本与未实现盈亏使用管理员手工成本；已实现盈亏独立按成交核算。** 持仓和行情自动读取；未填写的当前持仓成本显示「未设置」，不会被历史核算结果、当前市值或本金覆盖。

管理员登录后先在「管理账户」选择朋友账户，再点击「成本管理」，填写各币平均单位成本（USDT / 枚）并保存。同一绑定账户的所有用户共享这套成本。0 表示明确零成本，留空清除设置，USDT 基准固定为 1。后续买入不会改变手工成本。

- **Equity**：优先读取 `GET /sapi/v1/asset/wallet/balance?quoteAsset=USDT` 返回的 `walletName=Spot` 的 `balance`，再加合约接口的 USDT 权益，不汇总资金或其他钱包。接口不可用或使用测试网时，才退回现货余额（可用 + 冻结）× 行情估算；仅回退估算时在数值旁标注「估算」。手工成本不影响 Equity，净值快照也使用同一取值规则。
- **未实现盈亏**：非稳定币持仓数量 ×（最新价格 − 管理员单位成本）。手工成本保存后即可计算，不等待成交回溯；缺任一非稳定币持仓成本或行情时总额为未知。USDT、USDC、FDUSD、DAI、TUSD、USDP 的持仓浮盈显示「—」，不计入未实现盈亏汇总，但仍按实际行情计入总资产估值。
- **已实现盈亏**：成交记录的平仓收益减全部已经发生的买卖手续费。买入手续费发生时立即扣除，不等待卖出；后续卖出按不含已扣费用的历史买入成本移动加权平均匹配，避免重复扣费。只有买入、没有卖出时，已实现盈亏就是负的买入手续费。手工持仓成本变更不影响已实现盈亏。买入扣本币手续费时，按成交均价折算费用并从历史库存成本中剔除；卖出扣本币时释放额外支付数量的历史成本。
- **现金**：仅 USDT 可用 + 冻结余额，并分别展示。不受成本设置影响。
- **账户本金**：管理员登记的初始投入；不用于倒推已实现盈亏。

成交历史自动发现、分页同步，用于交易列表及已实现盈亏的内部成本匹配；不修改管理员持仓成本。历史同步期间，只要已经读取的成交可以核算，就显示暂计值并标注「暂计」；随着更多记录到达会调整。尚无成交且仍在同步、历史买入数量不足、缺手续费汇率或存在非 USDT 成交时为未知。Binance 现货接口不直接返回已实现盈亏字段。API 目录不可发现的下架交易对、闪兑及资金流水不在成交记录范围；不同交易对分批查询，不保证全生命周期历史完整。每轮最多 24 页，每页 1,000 笔，页面每分钟推进，列表显示最新 1,000 笔。

BNB 等第三币手续费使用成交所在分钟的 `ASSETUSDT` 历史 K 线收盘价近似折算；只接受已经结束的对应分钟，不使用当前价格或手工成本。买卖手续费折算后立即计入费用。没有对应历史行情时保留未知，不将稳定币手续费一律按 1 折算。每轮最多补查 12 个分钟汇率，结果与失败重试时间随账本保存，失败至少 5 分钟后重试。手续费支付会减少手续费币的可匹配库存，但不另计非成交的代币支付损益。

本地手工成本保存到私密 `.slzb/costs/`，成交进度在 `.slzb/ledgers/`。Vercel 网页修改成本**必须配置 Neon `DATABASE_URL`**，否则拒绝保存以免重启丢失。数据库同时保存净值和成交进度；成本保存后不需要 Redeploy。导出配置会带上当前手工成本，已存在的数据库成本记录优先于导入配置。固定管理员模式下，用户与 API 配置修改即时生效，不需要重新部署。

成本按账户、环境、API Key 指纹隔离；更换 Key 后需重新登记或迁移成本。服务端校验管理员角色及 Origin，只有管理员可通过 accountId 选择其他启用账户；普通用户始终限于自己绑定账户，无法调用成本管理接口。保存要求 revision 防止覆盖别人刚保存的内容，并保留最近 100 次修改审计。旧 `costs` 字段可作为尚未网页保存时的手工初值，旧 `performance` 仅保留兼容 API 字段。

报价为 USDT；其他稳定币按市场价格估值。未知行情资产保留在列表、不计入持仓明细小计；有官方 Equity 时仍可记录净值，只有本地估值不完整时才暂停快照。明细行情与官方估值的时间和口径可能不同，明细合计不保证与 Equity 完全一致；资产占比按已估值持仓明细合计计算。历史快照不会追溯改写。24h 涨跌和净值曲线不等同于资金流调整后的收益率。

接口依据：[Binance 账户与成交文档](https://developers.binance.com/en/docs/catalog/core-trading-spot-trading/api/rest-api/account)、[钱包估值文档](https://developers.binance.com/en/docs/catalog/core-trading-wallet/api/rest-api/asset#query-user-wallet-balance)。现货公开账户/钱包接口没有对应的未实现盈亏字段，按管理员成本计算；合约仓位使用合约接口返回的开仓价与未实现盈亏；统一保证金账户暂不支持。

## 合约持仓合并展示

真实账户自动复用所选账户 API 读取 Binance USDⓈ-M USDT 保证金合约，无需填写划转值或手工合约成本。旧划转配置不再参与计算，管理入口及 `/api/futures` 设置接口已移除；保留历史数据库记录，不执行删除迁移。

只读取 `GET /fapi/v3/account`（账户权益）、`GET /fapi/v3/positionRisk`（仓位、开仓价、标记价格、未实现盈亏）、`GET /fapi/v1/income`（资金流水）、`GET /fapi/v1/userTrades`（逐笔成交）。不交易、不实际划转。API 须允许这些查询；测试网密钥只发往 `demo-fapi.binance.com`。币本位、组合保证金与非 USDT 保证金持仓暂不支持。

- **总资产**＝现货钱包 Equity＋合约账户 USDT `marginBalance`。合约权益已经包含浮盈、已入账手续费、资金费及平仓收益，不再加仓位名义金额或任何盈亏。缺失合约权益时显示已知现货小计，并暂停净值快照；历史流水未同步不影响官方权益和快照。
- **已实现盈亏**＝现货已实现盈亏＋合约 `REALIZED_PNL`＋带符号的 `COMMISSION`；买卖手续费各自在发生时扣除，资金费不计入此项。首次流水未读到时可用已读取成交的平仓收益减手续费暂计，不与流水重复相加。
- **持仓盈亏**＝现货持仓盈亏＋合约未实现盈亏＋累计 `FUNDING_FEE`（收取为正、支付为负）。流水未齐时仍显示接口浮盈加已知资金费，并标注暂计。合约收益率按开仓名义成本计算，不使用杠杆保证金收益率。
- **持仓列表**统一展示数量、成本、标记价格、估值、盈亏及收益率。合约成本使用接口开仓均价，保留合约及方向标记。合约估值为数量×标记价格，仅展示仓位，不能再次累加到 Equity。资产分布使用合约实际权益作为独立部分；现金栏仍为现货 USDT。
- **交易记录**合并现货与合约逐笔成交，按时间倒序，合约记录标记来源，CSV 导出包含市场。ID 按市场＋交易对＋成交 ID 区分。近期成交优先读取，历史成交使用 ID 游标回补并持久保存。
- 同一合约双向持仓合并一行，数量和成本按绝对数量加权，盈亏使用多空盈亏之和，资金费只加一次。已平仓合约有累计资金费时保留一行；重新开仓仍使用该标的累计资金费。
- 初次读取最近 89 天流水，交易所历史接口仅保留约三个月；后续增量同步并持久保存，不能宣称覆盖账户全部历史。流水按类型＋交易 ID 去重，保留 64 位 ID 精度。第三币手续费按事件分钟行情近似折算；读取失败、历史缺口或缺失汇率会提示，不视作确定的零。

接口文档：[账户 V3](https://developers.binance.com/docs/derivatives/usds-margined-futures/account/rest-api/Account-Information-V3)、[持仓 V3](https://developers.binance.com/docs/derivatives/usds-margined-futures/trade/rest-api/Position-Information-V3)、[资金流水](https://developers.binance.com/docs/derivatives/usds-margined-futures/account/rest-api/Get-Income-History)、[成交](https://developers.binance.com/docs/derivatives/usds-margined-futures/trade/rest-api/Account-Trade-List)。

## 平仓复盘

左侧「平仓复盘」按资产与市场汇总所有已同步的平仓成交（不受交易表最近 1,000 笔限制），支持已清仓/部分平仓筛选、搜索、收益排序、逐笔明细和收益对比。剩余估值严格小于 1 USDT 视为已清仓，等于 1 仍为部分平仓；行情未知时不推断清仓。只有买入、未发生平仓的标的不进入复盘。

复盘使用成交历史移动加权成本，不使用当前手工持仓成本。买入手续费按已平数量分摊，卖出手续费在对应平仓扣除；未平仓部分的买入费用不计入复盘净收益，因此该值可以与账户总览立即扣费的已实现盈亏不同。资金费维持原口径计入持仓盈亏，不计入复盘净收益。合约使用交易所逐笔平仓毛收益；开仓费用按平仓数量匹配，反手成交拆分平仓和新开仓，多空双向分别维护库存。

收益率＝平仓净收益 / 已平部分匹配成本；均价按平仓数量加权，持有时间按库存加权开仓时间匹配，再按平仓数量加权。汇总显示累计已平数量、开/平均价、毛收益、手续费、净收益、收益率、平均持有时间、剩余估值和最近平仓。展开显示最近 100 笔明细，汇总仍包含全部已同步记录。缺少买入记录或手续费历史汇率的指标显示未知，不用零成本替代；同步不全时标为暂计。

价格（成本、标记价、成交价、委托价和复盘均价）大于等于 1 时显示两位小数，介于 0 与 1 之间显示四位；极小非零价格用 `<0.0001` 避免显示假零。所有计算保留十进制原始精度。
