# 币资产与币本位合约账本

同一资产跨现货钱包与 COIN-M 钱包使用统一移动加权成本。只对发生币本位钱包活动的资产启用；其他现货保留管理员手工成本。管理员的旧成本记录保留，但不再覆盖这些资产的账本均价。

## 数量与成本

- 实际持币 = 现货 free + locked + COIN-M walletBalance。marginBalance 中未结算的合约盈亏不是已收到的币。
- 内部划转只改变存放位置，不改变取得成本，不产生收益。
- 实际现货买入按成交金额增加成本，手续费立即费用化。
- 合约平仓收益、资金费、佣金返还实际增加币时，以事件所在分钟的历史 USDT 收盘价建立新增币成本。这是报告折算近似，不是 Binance 将收入兑换成 USDT。
- 支付币手续费、资金费或结算亏损时，按移动均价移除对应币成本，同时将支付时价值与移除成本之差作为币支付价差计入已实现盈亏。费用／亏损本身仅由合约流水计入一次。
- 现货卖出按同一移动均价结转成本；同一毫秒先处理现货成交，再按流水类型与 ID 固定顺序处理结算记录。

## 收益与权益

已实现盈亏 = 现货卖出收益 − 逐笔现货手续费 + 合约平仓收益 − 合约手续费 + 手续费返还 + 币支付价差。

持仓盈亏 = 现货与保证金币的币价盈亏 + 合约未结算盈亏 + 累计资金费（按事件时折算）。资金费已增加币成本，因此此处加上资金费不会再计算一次到账收入。

Equity 继续取交易所钱包权益相加。币本位 marginBalance 已包含未结算收益；展示合并币持仓、结算流水或合约名义金额均不再增加 Equity。

现货列表合并展示实际币资产。展开后区分钱包位置、持币成本、币价盈亏、合约已结算币收入、资金费、手续费、手续费返还和未结算收益。现货交易计划使用跨钱包均价，但只能出售现货钱包持币及假设已买入的币。平仓复盘不会因转入保证金而判定清仓。

## 对账与边界

每次账户同步按已保存的成交与收入流水重建，使用 Decimal，收入 ID 去重，并保留 64 位整数。SAPI MAIN_CMFUTURE / CMFUTURE_MAIN 历史独立分页，验证划转净额加结算收入与 COIN-M walletBalance 一致；再验证整个币池数量与现货加保证金余额一致（8 位币精度）。

缺少买入、划转、历史汇率，存在未知收入类型、跨币成交或数量不匹配时，不把旧手工成本套到全部余额；均价、相关盈亏显示待核对。当前没有为外部充值、提币、闪兑、理财等非已覆盖事件自动推断取得成本。既有历史接口回溯范围也不会因此扩大；不能用余额对上来证明范围外的历史完整。

行情仍每 5 秒更新，仅重估当前币余额和未结算合约；取得成本和已结算流水保持不变。账户／历史同步仍为 10 分钟一次或手动触发，不新增数据库轮询。

接口依据：[Binance COIN-M 账户与收入](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-coin-m-futures/api/rest-api/account)、[Binance 钱包划转历史](https://developers.binance.com/en/docs/catalog/core-trading-wallet/api/rest-api/asset)。
